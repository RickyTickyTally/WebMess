# Инструкция по деплою бэкенда Site Chat

Чтобы чат работал на компьютерах у вас и ваших друзей, сервер необходимо разместить на постоянном публичном хостинге. 

Самый простой, бесплатный и надежный способ для Node.js + WebSockets — это хостинг **Render.com**.

---

## Шаг 1. Подготовка и заливка на GitHub

1. Инициализируйте Git-репозиторий в папке бэкенда:
   ```bash
   cd backend
   git init
   git add .
   git commit -m "Initial commit for backend"
   ```
2. Создайте новый **публичный** или **приватный** репозиторий на вашем [GitHub](https://github.com).
3. Привяжите локальный репозиторий к удаленному и отправьте код:
   ```bash
   git remote add origin <ссылка_на_ваш_репозиторий_github>
   git branch -M main
   git push -u origin main
   ```

---

## Шаг 2. Развертывание на Render.com

1. Перейдите на сайт [Render.com](https://render.com/) и войдите через свой аккаунт GitHub.
2. В панели управления нажмите кнопку **New** (в верхнем правом углу) -> **Web Service**.
3. Выберите репозиторий с бэкендом, который вы только что залили на GitHub.
4. Настройте параметры службы:
   * **Name:** `site-chat-backend` (или любое другое уникальное имя)
   * **Region:** Выберите ближайший к вам (например, *Frankfurt*)
   * **Language:** `Node`
   * **Branch:** `main`
   * **Build Command:** `npm install`
   * **Start Command:** `npm start`
5. Прокрутите вниз и выберите бесплатный тариф **Free Instance Type**.
6. Нажмите кнопку **Create Web Service**.

Render начнет сборку проекта. Это занимает обычно 2-3 минуты. Когда статус сменится на **Live**, вверху страницы появится ваша постоянная публичная ссылка (например, `https://site-chat-backend.onrender.com`).

---

## Шаг 3. Настройка расширения под ваш сервер

Когда сервер запущен в облаке, обновите файлы в папке `extension`:

1. В файле **`popup.js`** замените локальный хост на вашу полученную ссылку:
   ```javascript
   const SERVER_URL = 'https://site-chat-backend.onrender.com'; // Ссылка от Render
   ```
2. В файле **`manifest.json`** добавьте вашу ссылку в разрешения `host_permissions`:
   ```json
     "host_permissions": [
       "https://site-chat-backend.onrender.com/"
     ]
   ```
3. Перейдите в браузере на `chrome://extensions/` и нажмите **Обновить (Reload)** на карточке расширения.

---

## Готово!
Теперь вы можете запаковать папку `extension` в ZIP-архив и отправить другу. Когда он установит его в свой Chrome, вы сможете общаться на любых сайтах в режиме реального времени!
