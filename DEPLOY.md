# Инструкция по деплою бэкенда Site Chat на Glitch.com

Чтобы чат работал в онлайне бесплатно и без ввода банковских карт, мы воспользуемся сервисом **Glitch.com**. 

Glitch идеально подходит для хостинга Node.js с поддержкой WebSockets, не требует верификации картами и запускает проект за пару кликов прямо из GitHub.

---

## Шаг 1. Импорт проекта в Glitch

1. Перейдите на сайт **[Glitch.com](https://glitch.com/)** и войдите через свой аккаунт **GitHub** (или Google).
2. Нажмите кнопку **New Project** (в правом верхнем углу).
3. В выпадающем меню выберите пункт **Import from GitHub** (внизу списка).
4. Введите адрес вашего репозитория:
   `https://github.com/RickyTickyTally/WebMess`
5. Нажмите **OK**.

Glitch склонирует проект и автоматически запустит его в облаке (благодаря специальному файлу `package.json` в корне, который указывает запускать `node backend/server.js`).

---

## Шаг 2. Получение публичной ссылки

1. В левом нижнем углу интерфейса Glitch нажмите кнопку **Share** (Поделиться).
2. Перейдите во вкладку **Live Site**.
3. Скопируйте ссылку на ваш работающий проект (она выглядит примерно так: `https://your-project-name.glitch.me`).

---

## Шаг 3. Настройка расширения под ваш сервер

Теперь обновите файлы в вашей локальной папке `extension`:

1. В файле **`popup.js`** замените локальный адрес сервера на вашу ссылку от Glitch (обратите внимание, протокол должен быть `https`):
   ```javascript
   const SERVER_URL = 'https://your-project-name.glitch.me'; 
   ```
2. В файле **`manifest.json`** добавьте этот адрес в разрешения `host_permissions`:
   ```json
     "host_permissions": [
       "https://your-project-name.glitch.me/"
     ]
   ```
3. Перейдите в Chrome на страницу `chrome://extensions/` и нажмите **Обновить (Reload)** на карточке вашего расширения.

---

## Готово!
Теперь расширение подключается к вашему бесплатному и безопасному серверу на Glitch. Вы можете запаковать папку `extension` в ZIP и отправить её вашему другу — чат будет работать!
